# Calculadora de Conversão de Bases Numéricas

Este é um projeto acadêmico desenvolvido em **Python** para realizar a conversão automática de valores entre quatro bases numéricas: **Decimal, Binária, Octal e Hexadecimal**.

---

## 🛠️ Funcionalidades do Projeto
* **Conversão Multibase:** Recebe um valor em qualquer uma das quatro bases e apresenta as três conversões equivalentes de forma simultânea.
* **Validação de Dados:** O sistema valida o dado inserido de acordo com a base escolhida (ex: impede que o dígito `3` seja digitado em uma base binária).
* **Interface Interativa:** Menu intuitivo em terminal que permite múltiplas operações até que o usuário decida encerrar.

## 📁 Estrutura do Código
O projeto foi estruturado seguindo boas práticas de programação, dividindo as responsabilidades em funções limpas e legíveis.

## 🔧 Como Executar Localmente
Caso prefira rodar o projeto em sua máquina:
1. Certifique-se de ter o Python instalado.
2. Baixe o arquivo `calculadora_bases.py`.
3. Abra o terminal na pasta do arquivo e execute o comando:
   ```bash
   python calculadora_bases.py
   ```
